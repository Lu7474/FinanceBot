# FinanceBot

Telegram-бот для ведения личной финансовой отчетности с возможностью отслеживания доходов и расходов, создания отчетов и анализа трат по категориям.

## Возможности

- **Добавление доходов и расходов** — быстрый ввод операций с категориями
- **Быстрый ввод** — просто напишите `+5000 зарплата` или `-200 кофе`
- **История операций** — просмотр записей за любой период с пагинацией
- **Детальные отчеты** — круговые диаграммы по категориям
- **Удаление записей** — с подтверждением и навигацией
- **Удобный интерфейс** — интуитивные кнопки и меню

## Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <your-repo-url>
cd FinanceBot
```

### 2. Создание виртуального окружения
```bash
python -m venv env
```

### 3. Активация виртуального окружения

**Windows:**
```bash
env\Scripts\activate
```

**Linux/MacOS:**
```bash

```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Настройка конфигурации

Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=your_telegram_bot_token_here
```

### 6. Запуск бота
```bash
python bot.py
```

## Использование

### Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и показ главного меню |
| `/help` | Справка по боту |
| `/cancel` | Отмена текущей операции |

### Кнопки меню

| Кнопка | Описание |
|--------|----------|
| **Доход** | Добавление записи о доходе |
| **Расход** | Добавление записи о расходе |
| **История** | Просмотр истории операций |
| **Отчёт** | Создание отчета с диаграммой |
| **Удалить запись** | Удаление записей |

### Формат ввода записей

**Через кнопку:**
```
1000 зарплата
500 еда
2000 покупки
```

**Быстрый ввод (без кнопки):**
```
+5000 зарплата
-200 кофе
-1500 такси
```

**Несколько записей сразу:**
```
+50000 зарплата
-1000 продукты
-500 транспорт
```

### Периоды истории

- **Сегодня** — записи за текущий день
- **Вчера** — записи за вчерашний день
- **7 дней** — записи за последнюю неделю
- **30 дней** — записи за последний месяц
- **Этот месяц** — записи с начала месяца
- **Прошлый месяц** — записи за прошлый месяц
- **Этот год** — записи с начала года
- **Свой период** — ввод дат вручную (формат: `01.01.25 - 31.01.25`)

### Создание отчетов

1. Нажмите **Отчёт**
2. Выберите тип: **Доход** или **Расход**
3. Выберите год
4. Выберите месяц
5. Получите круговую диаграмму с детализацией по категориям и датам

## База данных

### Таблица `users`
| Поле | Тип | Описание |
|------|-----|----------|
| id | int | Уникальный идентификатор |
| tg_id | bigint | Telegram ID пользователя |
| name | str | Имя пользователя |
| phone | str | Номер телефона (опционально) |
| created_at | datetime | Дата регистрации |

### Таблица `records`
| Поле | Тип | Описание |
|------|-----|----------|
| id | int | Уникальный идентификатор |
| user_id | int | Связь с пользователем |
| operation | str | Тип операции ("+" или "-") |
| amount | decimal | Сумма операции |
| category | str | Категория (max 50 символов) |
| created_at | datetime | Дата создания |

### Индексы
- `ix_records_user_created` — ускорение выборки по периодам
- `ix_records_user_operation` — ускорение отчётов по типу
- `ix_records_user_op_cat` — ускорение GROUP BY по категориям

## Ограничения

| Параметр | Значение |
|----------|----------|
| Максимальная сумма | 1 000 000 |
| Длина категории | 50 символов |
| Записей на странице | 15 |
| Rate limit | 20 запросов/мин |
| Категорий на графике | 7 (остальное — "Прочее") |

## Известные особенности

- Временная зона: Москва (UTC+3)
- При большом количестве категорий в отчете (>7) остальные объединяются в "Прочее"
- Caption фото автоматически обрезается до 1024 символов
