# FinanceBot 🤖💰

Telegram-бот для ведения личной финансовой отчетности с возможностью отслеживания доходов и расходов, создания отчетов и анализа трат по категориям.

## Возможности

- **➕ Добавление доходов и расходов** - быстрый ввод операций с категориями
- **История операций** - просмотр записей за день, месяц, год или произвольный период
- **Детальные отчеты** - круговые диаграммы расходов по категориям
- **🗑️ Удаление записей** - возможность удаления ошибочных записей
- **📱 Удобный интерфейс** - интуитивные кнопки и меню

## 🛠️ Технологии

- **Python 3.8+**
- **aiogram 3.x** - современный фреймворк для Telegram ботов
- **SQLAlchemy 2.x** - ORM для работы с базой данных
- **SQLite** - легковесная база данных
- **matplotlib** - создание графиков и диаграмм
- **pytest** - тестирование

## 📋 Требования

- Python 3.8 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## ⚙️ Установка и настройка

### 1. Клонирование репозитория
```bash
git clone <your-repo-url>
cd FinanceBot
```

### 2. Создание виртуального окружения
```bash
python -m venv env
```

### 3. Активация виртуального окружения

**Windows:**
```bash
env\Scripts\activate
```

**Linux/MacOS:**
```bash
source env/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Настройка конфигурации

Создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=your_telegram_bot_token_here
DATABASE_URL=sqlite+aiosqlite:///db.sqlite3
```

### 6. Запуск бота
```bash
python bot.py
```

### Формат ввода записей

При добавлении дохода или расхода введите сумму и категорию:
1000 зарплата
500 еда
2000 покупки


### Просмотр истории

Выберите период для просмотра:
- **Сегодня** - записи за текущий день
- **Месяц** - записи за текущий месяц
- **Год** - записи за текущий год

### Создание отчетов

1. Выберите год для отчета
2. Выберите месяц
3. Получите круговую диаграмму расходов по категориям

## 🗄️ Структура базы данных

### Таблица `users`
- `id` - уникальный идентификатор пользователя
- `tg_id` - Telegram ID пользователя
- `name` - имя пользователя
- `phone` - номер телефона (опционально)
- `created_at` - дата регистрации

### Таблица `records`
- `id` - уникальный идентификатор записи
- `user_id` - связь с пользователем
- `operation` - тип операции ("+" для дохода, "-" для расхода)
- `amount` - сумма операции
- `category` - категория операции
- `created_at` - дата создания записи

- Используйте асинхронные функции где возможно

## Известные проблемы

- При большом количестве категорий в отчете (>7) остальные объединяются в "Прочее"
- Временная зона жестко задана как Москва (UTC+3)
